# V3 真实圆桌与酒馆环境

实现文件：`public/roundtable-scene.js`、`public/tavern-models.js`、`public/tavern-environment.js`。

本轮未修改计分、经营规则、主持模型、权限或数据存储。

## 实际实现

- 桌体改为木纹厚桌板、木围裙与十字底座、细黄铜镶边；桌面有杯垫、陶杯、咖啡、笔记本与笔。
- 四位坐姿人物采用不同的低饱和布料夹克，增加衣领、衬衫、口袋、纽扣、袖口、手指、裤子和鞋。椅子改为木框、靠背软垫和黄铜扶手支撑。
- 场景有木地板、圆形地毯、后吧台、成排瓶罐、拱窗、暖色壁灯、黄铜天平与绿植。均是实际几何或本地Canvas纹理，没有采购/下载新素材。
- 人物头部以自然侧转保持归属，头像仍是所属人物头部的真实材质；移除了手机统一放大1.4倍与整个头部始终朝向镜头的旧处理。
- 姓名为单行身份锚点，提交状态只显示小点并保留完整可访问名称。分数留给外围经营区。
- 球面分区继续调用原 `territoryShares` / `territoryOwner`，未改全球份额公式。减少立柱数量与高度，取消默认飞线，减轻网格。
- 初始球体显示比例从 `.73` 改为 `.62`，交互缩放范围 `.84—1.12`。球体组包含所有标记的保守局部半径为 `2.02`；悬浮中心按 `桌高 + .13 + 2.02 × 实际缩放` 推导，因此所有方向旋转和允许缩放均保留至少`.13`的桌面间距。
- 正交镜头由桌体、人物与球体的实际三维包围盒计算取景，不依靠头像放大补偿小屏。
- Canvas保留`touch-action:pan-y`。只有真实球体投影圆形热区使用`touch-action:none`，拖动/双指手势局限在球体；其余区域可纵向滚动。
- 默认静止。没有图形状态变化时停止RAF和WebGL绘制；缩放、旋转、头像或经济数据变化才安排绘制。页面隐藏与场景离屏会暂停，重复房间快照不唤醒场景。详见 `SCENE_PERFORMANCE_2026-11-17.md`。

## 可查询证据

场景API仍兼容 `mountRoundtable` 原有返回值，并新增`getDiagnostics()`。

浏览器可读取：

```js
document.querySelector('.tavern-scene-v3').getSceneDiagnostics()
// 同时有 .dataset.sceneBounds 的简洁JSON摘要。

document.querySelector('.tavern-scene-v3').captureSceneImage()
// 同步重绘后返回独立场景的 data:image/png 字符串，场景销毁后返回null。
```

返回四席、实际占用席位、头像纹理、头部/标签投影范围、最小/默认/最大缩放的球体与全部标记包围底部、桌高、环境几何类别/数量、绘制计数等公开诊断。没有玩家私有研究或凭据。

同步快照也通过挂载API的`getSceneSnapshot()`暴露，仅用于本地参考采集；没有开启`preserveDrawingBuffer`。玩法仍由真实WebGL绘制。姓名按钮和头部点击区均至少44px，文字保持单行。

性能字段需按含义读取：`fps`是最近一秒实际提交绘制的帧数，`callbackFps`是RAF回调频率；`renderMode:'on-demand'`下静止画面的低绘制帧数属于节能行为，不能当作连续动画性能。连续旋转或拖动时才适合检查实际动画帧率。

## 首张真实手机图后的针对修复

首次实际场景PNG确认了桌面、人物、吧台、木地板和瓶罐已真实出现，但初始球体过暗、灯窗在窄屏边界外。初始四席分数均为0时中性区占100%、经营立柱为0属于正确状态，不能为填满画面生成虚假彩色份额。

随后补入自定义球体Shader的`toneMapping`与`colorSpace`输出片段，并提高蓝灰中性底色及浅色经纬网可读性；这些ShaderChunk已在本机Three r165中核实存在。首轮真实结算后再验证彩色份额和经营标记。

拱窗移到小屏可见范围，使用本地Canvas生成月色/远树玻璃纹理；暖色壁灯收窄，标牌与瓶架缩窄以免挤压人物。头像轮廓改为细哑光深灰，减少黄铜金币观感。姓名按钮保持44px透明命中区，去掉常驻黑底胶囊；脚本席只显示短名，完整身份保留在可访问名称与title中。

这些针对修复已通过语法及既有3项几何检查。

2026-11-17 已实际查看本目录 `evidence/scene-390--actual.png` 与 `evidence/scene-1440--actual.png`：手机中性球为可读的蓝灰经纬网；桌面场景包含清晰彩色份额与低矮标记，窗、壁灯与陈设已进入画面，四席与桌面关系可辨。场景PNG的视觉复验不等于整页操作、触控与完整六轮验收，后者仍由总控/独立QA记录。
