# V3 酒馆界面

本次在独立 V3 工程中重排酒馆，阅读、案例、札记及实际房间 API 保留。未修改经营规则、模型请求预算、权限或密钥。

## 结构

- `.v3-room > .arena-hud`：房间/产品或练习来源、阶段时间、更多。
- `.game-body`：左侧场景与行动、右侧 310px 信息栏（较窄桌面 290px）。
- `.arena-stage > #globe-container`：真实 Three 场景独立占位，行动区不盖在 canvas 上。
- `#economy-summary`：现金、综合分/名次、有效用户；平铺数据。
- `#insight-panel`：情报、研究、账本三页签。人物公开详情也在同一区域查看。
- `.arena-dock`：每阶段一个强调色动作。决策表单分成选择和预算确认两行。

900px 以下采用手机布局：固定顶部计时、经营摘要、紧凑场景、本轮情报摘要；底部持续显示行动和主入口。`.action-editor` 是可关闭的动作底部面板，右侧信息栏则复用为信息底部面板，两者互斥。`Escape` 可关闭面板；页签支持左右方向键/Home/End。

## 视觉约定

背景 `#141310`，面板约 `#1c1b17`，文字 `#eee9dd`，辅助 `#aaa396`，主操作 `#d17b54` 配深棕字 `#26170e`，更低优先级的说明至少提亮到 `#9b907a`，边线低亮黄铜。没有新增浏览器库或字体依赖，保留系统无衬线。辅助可见文本不低于13px，手机字段16px，主要操作15px。窄屏阶段使用 `R3/6 · 决策` 短文案，不缩小阶段文字。常态同步提示、旋转教学、每人多行数字和重复场景口号均取消。

主 stylesheet 为 `public/tavern-v3.css`，`index.html` 不再加载旧 `tavern-v2.css`。`roundtable.css` 只负责场景身份锚点与头像点击区域。原阅读 `style.css` 继续独立提供基础样式。

## 操作与真实性

- 主操作保留 `#action-form`、`#action-id`、`#action-target`、`#action-scale` 及真实 `act('action')`。
- 无需目标的行动会隐藏目标字段，服务端仍执行原校验。
- 预算显示已预留20固定运营费；收到提交回执不扣除前端现金，财务等待服务端结算。
- 草稿跨1秒轮询、页签切换、打开资料面板保留；回合切换才清理。
- `#receipt-status[data-state]`：`unsubmitted`、`draft`、`submitting`、`accepted`、`error`、`uncertain`、`locked`。
- 请求失败时保留选择和此前已接收动作；网络丢失响应不伪称失败或成功，先显示结果未确认，再按轮询的权威动作核对。
- 丢包后的确认只会清理与已确认动作相同的草稿，用户之后的新草稿继续保留。
- 截止后禁用确认，不依赖最多1秒后的阶段更新才锁界面。
- 主持按真实 provider 显示模板/DeepSeek及回退，不让精简 UI 隐藏来源。
- 练习模式在顶部持续标明三席脚本，手机以来源标记替代低频产品名。
- 私有研究只使用 `state.me.privateNotes`，人物详情只读当前 state 提供的公开字段。

## 实际截图后的微调

根据 `docs/evidence/reference-mobile-initial.png` 和桌面实际截图，手机舞台由最多530px收紧至370–410px，为桌面人物与消息、行动保留更合理的比例。三维场景本身仍按容器尺寸重新投影，四席的头部点击区保持至少44px。

场景、等待名单、账本与历史表中的脚本统一使用“火种”“常青”“罗盘”短名；练习来源由顶栏持续说明，不在每个名字后重复“脚本”。真人姓名不改写，仅对显示宽度做省略，完整姓名保留在title和资料入口中。席位标签去掉大块深色底框，让人物保持主体。

提交、开局、推进不再发覆盖主行动的重复toast，结果由回执与阶段直接表达。手机其余必要toast显示于固定主行动上方。微调后再次通过语法、模板结构和6项回执行为检查；更新后的真实浏览器截图由独立QA采集。

最终矩阵另发现桌面场景高度原由剩余空间分配，决策面板变短时舞台会变高、相机因此跳动。现将桌面舞台独立固定为 `clamp(320px, calc(100dvh - 392px), 520px)`，在900高视口为508px、800高为408px，不随阶段文字或行动表单高度改变。阶段面板依实际内容高度；超出剩余高度时仅其内部滚动。手机370–410px规则保持不变。

整页浏览器截图还发现首次决策的预算与作用说明为空：原先只在input或套用已提交动作时调用估算函数，未提交的初始默认动作漏了初始化。现由 `updateGame()` 在同步动作输入之后统一更新当前选择的预算与说明，也实时反映现金变化和全体行动的目标字段隐藏。`node docs/check-action-budget-init.mjs` 执行真实源函数，确认没有input事件的初始预算1180与说明非空，现金变动刷新预算、全体/定向行动的目标字段切换正确；同时6项回执行为仍通过。

手机行动面板展开时，背景固定条保留当前行动摘要，其“选择/更新行动”按钮隐藏并退出键盘与辅助技术导航，面板中的“确认/更新行动”成为唯一可见主操作；关闭面板后背景入口自动恢复。

## Agent 接入入口

用户反馈复制接入入口难找。现在房间顶栏在“更多”之外直接展示“连接我的 Agent”（手机为“连接 Agent”），使用低强调描边按钮，保留行动确认的唯一主按钮。连接通过后顶栏显示“我的 Agent”，连接状态依据服务端自检字段。

接入弹窗先展示全宽的“复制给我的 Agent”及粘贴去向，再显示实时自检状态与当前授权模式。完整个人指令、凭据撤销、偏好设置放入各自展开项；复制成功显示下一步提示，复制失败则展开并选中完整指令供手动复制。复制不改变授权、草稿或真实连接状态。撤销凭据后重置复制提示，要求重新复制新指令。
