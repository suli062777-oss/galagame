## 数据契约核查

核查文件：`server/api.js` 的 `publicLedger` / `project`，`worker/api.js` 的相同投影，`server/engine.js` 的 `RULES` / `scoreCompany` / `settle` / `publicProduct`。当前 Node 与 Worker 投影提供相同的关键字段。

| 需求 | 可使用的真实来源 | 品审边界 |
| --- | --- | --- |
| 本局任务 | `state.product.name/coreBehavior/northStar/segments` | 读取本局产品，不能硬编码 AI 笔记工具 |
| 分数组成 | `state.rules.weights`、参考值；`players[].contributions/scoreInputs` | 终局贡献来自真实结算，不能把现金当作额外分数项 |
| 结算摘要 | `history[].players[]` 的 action、cashBefore、previousUsers、actionCost、users、retained、newUsers、net、cash、profit、score、delta | 表述发生了什么，不凭一次涨跌给确定的因果归因 |
| 逐轮复盘 | `history[].round`、对应席位账本、`world` | history 没有每轮世界快照；过滤 `world.round <= 选中轮次` 后仍含同轮结算完成消息，故应标“截至这一轮结算的公开记录”，不能称决策前全部已知 |
| 情报 | `world[].type`，包括 fact / forecast / rumor / verification | 不按文案自行猜事实类型；没有传闻就不填一个占位传闻 |
| 私有研究 | `state.me.privateNotes` | 仅本人可见，不投到公共摘要或其他席位，不用于伪造他人研究 |
| 首轮行动 | `/api/config` 的完整 actions、scope、scales、cost、effect | 保留 A01–A12；客户端的分组是查找帮助，不改变行动定义 |
| 回执 | `state.me.action/receipt`、原有提交与超时处理 | 默认草稿 A01 和服务端超时兜底 A12 是不同概念，未确认不等于付费投放 |

关键规则仍为四席、六轮、45 秒共同决策；开局由房主发起；综合分规模 50%、累计利润 35%、留存 15%，归一化与破产逻辑按本局规则。界面方案不能通过教程、弹层或暂停按钮暗改这些规则。

### 3D 空白的定向诊断与更正

初版全页面 CDP 截图曾显示决策圆桌空白，已独立复查后撤回“阶段切换本身导致空白”的结论。仪器脚本为 `scripts/qa-classroom-scene-diagnosis.mjs` 与 `scripts/qa-classroom-scene-viewport.mjs`，原始证据分别保存在 `quality/scene-diagnosis/` 和 `quality/scene-diagnosis-viewport/`。

- 调用全页面截图后，临时布局改变视口，IntersectionObserver 导致场景 `suspended:true`；contextLost 始终为 false，CSS display/opacity 正常。该状态下现有 `captureSceneImage()` 诚实返回 null，没有声称强制绘制恢复成功。
- 全新浏览器只拍实际 viewport，不调用强制捕获 API 的第一轮图显示完整真实圆桌。展开/收起/桌面 resize/手机 resize 全部正常，renderCount 随实际变化由7增至12，调度器未挂起。
- 最终完整六轮证据改用实际 viewport 和自然滚动，场景通过。未要求产品为测试截图加入持续渲染或其他补丁。首页真实对局预览来源是强制绘制前的正常页面截图。
