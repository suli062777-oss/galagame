# 增长黑客 · Agent增长酒馆

**[打开线上四人版](https://growth-tavern-suli-demo.zheiisu.chatgpt.site/)**（公开链接，无需登录）。

完整交互书、增长实验、代码圆桌人物、可换头像、四人六轮同桌。线上已使用 Cloudflare Worker + D1 权威共享房间，DeepSeek 主持密钥只在运行时Secret中。所有实例共用最多12次生成请求预算（包括重试），用尽自动模板，游戏可继续。

进入酒馆选择四人同桌，填写称呼创建，复制不含凭据的邀请链接。四人入席后房主开局，每轮45秒共同决策。也可选择单人练习，其他三席明确为脚本。

`online/` 是真实线上服务源码及D1迁移；`demo/` 保留早期浏览器本地演示作为历史；根目录 `server/` / `public/` 是完整原生Node本地版。网站已不使用浏览器模拟服务器。

本地版：Node.js22+，运行 `sh scripts/start.sh`，打开http://127.0.0.1:3001/ 。线上构建见 `online/README.md`。

仓库不包含真实密钥、私人房间数据或玩家凭据。原始书籍为肖恩·埃利斯、摩根·布朗《增长黑客》；本项目是教学二次解读，经营公式为改编。AgentBar/Three.js版权说明保留。
